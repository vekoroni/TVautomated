# AVSHUNTER repository cleanup manifest — 2026-09-10

## Scope

This cleanup removes only regenerable Python bytecode caches and Python source
copies already held in confirmed archive/decommissioned locations. Items are
sent to the Windows Recycle Bin rather than permanently deleted.

Production modules, tests, historical reports, CSV evidence, pipeline run
artefacts, canonical databases, the live Phantom database, database backups,
macro archives, and active compatibility adapters are excluded.
