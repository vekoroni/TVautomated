## Bounded original-file download (tested 10 November 2026)

Use this supported CUA browser pattern only AFTER the exact source attachment and its unique viewer Download button are observed. Start the listener and click in the SAME call, not successive calls. Tool timeout 25000 ms; event timeout 15000 ms, click timeout 5000 ms, path timeout 5000 ms. One attempt per export, then source-preview fallback. A timeout is not permission to retry indefinitely.

```javascript
var result = await Promise.all([
  tab.playwright.waitForEvent('download', {timeoutMs: 15000}),
  tab.playwright.getByRole('button', {name: 'Download', exact: true}).click({timeoutMs: 5000})
]);
nodeRepl.write(await result[0].path({timeoutMs: 5000}));
```

This is a browser UI download, not a shell/network fetch. Verify the returned filesystem path, exact JSON bytes, producer checksum and source message independently before intake. The rev75 replay completed in 16.3 seconds; the independent source-pane replay also recovered all 1129 lines and matched its 50835 bytes / SHA-256. This does not prove every future website download succeeds; the bounded fallback and authentication handoff remain required.
