## 2. P0 — immediate release risk, before any further build

Verified in the working tree on 27 Sep (uncommitted): `evening_workflow` now imports three **untracked** modules (`contracts/descriptive_forecast_packet.py`, `contracts/expression_candidate_packet.py`, `contracts/expression_valuation_packet.py`) and treats each publisher as **critical**: any exception returns `False` and aborts the Evening run before Options Intelligence. `tests/test_avs_int001_stage0.py::test_named_production_imports_are_in_the_git_index` fails for exactly these three files. Consequences:

- a clean checkout (or a machine without these files) aborts every Evening run at Vanguard exit;
- an incomplete C6/C8 publisher can stop a normal production Evening even though nothing downstream is permitted to consume its output yet;
- this contradicts the design's own release rule (§8: new artefacts beside existing files, dual-read through an adapter, rollback by versioned configuration).

**P0 actions (tonight, before anything else):** (a) make the three publishers non-critical behind a versioned configuration flag defaulting **off**, logging a typed `FORECAST_PUBLICATION_SKIPPED`/`_FAILED` state, so the Evening path is byte-identical to the committed baseline when the flag is off; (b) either commit the three modules with their tests or remove the imports until they are governed, so the S0 import-closure test is green; (c) record the flag in the run manifest. Failing test first: an Evening dry-run fixture with the modules absent, and one with a raising publisher, must complete Vanguard→Options unchanged.

## 3. Independent design review (27 Sep, separate reviewer, read-only)

The reviewer read the design, the four TEV receipts, CLAUDE.md, the governing spec v1.1, the addendum, the G1–G4 definitions, INT-001 §1, the working-tree diff and the untracked module headers. Findings, in substance:

**3.1 Complexity per component.** Required by the spec: separating direction from contract (C5), bounded C6 generation without a pre-selector, C7 before valuation with IV dynamics as a versioned assumption, a common C8 path set with ask entry and bid exit, competing risks with shrinkage to pooled states and block bootstrap (spec §8). **Not required by any section:** the empirical-Bayes hierarchy with fitted kappa, the pre-registered Wyckoff × compression challenger, the four-part support floors and the 0.40 interval rule, the extra C5 vocabulary (BULL/BEAR/NEUTRAL_RANGE plus four `forecast_state` and five `estimation_reliability_state` values where spec §9 already has SUPPORTED/OPPOSED/UNSUPPORTED/INSUFFICIENT_EVIDENCE), Morning numeric revaluation while everything is shadow, and the HAR / IV-percentile items (spec §11 "for example").

**3.2 Contradictions and authority drift.**
1. **Macro conditions the forecast** (design §4.1 and §4 item 1) against spec §26, §7, App. A.2, addendum D10 and CLAUDE.md rule 6. A solution design cannot amend the governing spec; either ACK amends the spec (A.7 pattern) or the feature is removed. Design §9 item 2 remains open.
2. **An uncalibrated numeric EV is published where evidence is insufficient.** `contracts/expression_valuation_packet.py` computes `research_ev` (policy `unconditional_same_ticker_20_session_blocks_v1`) for every row although every row is `NOT_ESTIMABLE`; the Lab shows it. This exceeds the design (§3: `DESCRIPTIVE_ONLY` carries no numeric EV; §5.3: C8 fits no second per-ticker model) and the spec (§9 and §21 route INSUFFICIENT_EVIDENCE to NOT_VALUED; §12 requires the path set to reconcile to the evidence packet; §8 makes the market universe, not one ticker, the base sample).
3. **Parallel owners built beside existing ones** (rule 4, R2): `domain/forecast_path_label.py` and `domain/competing_path_estimator.py` duplicate `avshunter/c12_outcome/passage.py`, `estimators.py`, `base_rate.py`; `domain/candidate_expression.py` duplicates `domain/contract_family_generation.py`; `domain/option_path_valuation.py` and `domain/vectorized_research_ev.py` duplicate `domain/deterministic_option_valuation.py` and `avshunter/c12_outcome/expression.py`. The design's source register never names DOI-001, MON-003 or `avshunter/c12_outcome`.
4. **S0 feasibility measured on the wrong sample:** floors tested on 195 starts from AVSHUNTER's own runs, while spec §8 makes the point-in-time market universe the base sample and own outcomes an additional calibration source. This produced "NOT_ESTIMABLE everywhere" and, in turn, the research-EV workaround.
5. **Presentation publishes a domain aggregate:** `contracts/lab_control.py` calls `load_or_publish_descriptive_packet` (spec §18: the Lab is a read model).
6. **Expression scope narrowed to long calls/puts** drops shares (spec §10, ACK Q1); if ACK's sign-off covers it, the scope decision must be versioned in configuration.
7. No rank or gate authority has been granted anywhere: consistent with Invariant G and G1–G4.

**3.3 Top risks in the in-progress code.** (1) Advisory publishers wired as hard stops of Evening; `lab_control` raises on reconciliation failure; `morning_handoff_finalizer` calls `publish_morning_revisions` unguarded; the packets' immutability check raises on a differing rerun. (2) Evening runtime unmeasured: the research EV reads the price database per ticker; 50 tickers took 39 s with one candidate, about 18 min for 1,370, unmeasured with up to 20 candidates. (3) Uncalibrated EV numbers shown to the trader (e.g. VST −47.6 % base, −54.8 % adverse) invite anchoring. (4) Two labellers, two estimators, three pricers and two generators will drift (ambiguous-touch handling, σ versus ATR units). (5) The release is not clean (R8): about 2,250 untracked TEV lines and 441 modified tracked lines share one tree with unrelated SOR-001, WAR, PKG and archive changes; unverified whether the later catalyst-truth pass still patches Discovery files after the C5 hash is frozen.

## 5. Definition of done per slice

Test-driven design → domain-driven design → failing test → build → focused tests → integrate into the real pipeline path → replay/regression → acceptance evidence → commit last. `IMPLEMENTED_PENDING_LIVE_ACCEPTANCE` where an ACK-started run is required; `TESTED_UNCOMMITTED` at most before commit. No grade 0/1/2 defect may remain for shipment; grade 3 needs a documented workaround. A non-numeric descriptive result is honest but does not satisfy the signed objective of a supported C4/C8 monetary valuation; it is reported as such, never rebadged.
