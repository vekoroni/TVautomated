SCOPE
This slice extends the compact read-only presentation projection. It does not
change trading direction, rank, verdict, valuation, execution authority or sizing.

No Lab restart, pipeline run, paid provider call, order, live database update or
frozen run artifact modification was performed.

IMPLEMENTED
1. contracts/lab_review_sources.py prepares exact-run source data for publication.
   Accepted interpreter handoffs must pass the existing production acceptance and
   artifact-integrity validator. Overlays match run/ticker/thesis/trade idea and
   selected contract, not ticker alone. Protected decision fields are retained.
2. Morning validation can reuse the finalizer's successful identity reconciliation
   receipt instead of reopening thousands of event files. Missing events remain
   explicit. The fallback independently reads exact matching validation events.
3. Canonical BEH001 compression readings are carried from Discovery for the exact
   governing lane candidate and thesis timeframe. This repairs a presentation
   handoff gap: canonical compression existed in Discovery but not the final book.
   No daily-for-weekly substitution or legacy Crabel fallback is introduced.
4. Macro and sector rotation context come from pinned run artifacts. Bias and
   breadth timestamps are separate. Only published P10 sector returns are shown;
   missing returns and unpublished money flow are not inferred as neutral.
5. The Morning compact publication occurs after handoff acceptance and summary
   publication, avoiding an early duplicate projection build.
6. review.html, review-app.css and review-app.js provide sector overview/filtering,
   paginated rows, concise trade cards, lazy evidence families and saved reports.
   Rows load independently of Macro. Drawer failures are local and retryable.
   Source text is escaped and requests are revision-pinned. Loading this screen
   neither calls the wide legacy book endpoint nor generates paid reports.
   Paid report generation remains an explicit link to the existing desk workflow.
